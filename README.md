# Inquira

**A simple, structured AI Q&A application powered by LangChain.**

Inquira is an AI-powered question-answering application built with LangChain, supporting multiple LLM providers through OpenAI and Anthropic APIs.

## Features

- **Multi-Provider LLM Support** — Integrates OpenAI and Anthropic
  models through their respective APIs.
- **Natural Language Question Answering** — Processes user queries
  and generates AI-powered responses.
- **Structured Outputs** — Generates consistent, schema-validated
  responses using Pydantic.
- **Confidence Scoring** — Provides LLM-generated confidence scores
  alongside answers.
- **Error Handling** — Handles API and model invocation failures.
- **LangSmith Observability** — Enables tracing and debugging
  of LLM interactions.

## Tech Stack

- **Python** — Core programming language
- **LangChain** — LLM application framework
- **Pydantic** — Structured data validation
- **LangSmith** — LLM tracing and observability

## Installation

### Prerequisites

Before getting started, ensure you have the following installed:

- Python 3.12 or higher (or the version specified in `pyproject.toml`)
- [uv](https://docs.astral.sh/uv/) — Python package and project manager
- API keys for OpenAI and/or Anthropic

### 1. Clone the Repository

```bash
git clone https://github.com/binaryCoder-101/inquira.git
cd inquira
```

### 2. Install Dependencies

Install the project dependencies using `uv`:

```bash
uv sync
```

This automatically creates a virtual environment and installs the dependencies defined in `pyproject.toml`.

### 3. Activate the Virtual Environment (Optional)

**Linux/macOS:**

```bash
source .venv/bin/activate
```

**Windows (PowerShell):**

```powershell
.venv\Scripts\Activate.ps1
```

> Activating the virtual environment is optional when using `uv run`, as it automatically uses the project's environment.

### 4. Configure Environment Variables

Create a `.env` file in the project root and add your API credentials:

```env
OPENAI_API_KEY=your_openai_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
LANGSMITH_API_KEY=your_langsmith_api_key

# Optional defaults:
LLM_PROVIDER=openai
OPENAI_MODEL=gpt-4o-mini
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
LLM_TEMPERATURE=0.3
```

> **Security:** Never commit your `.env` file or expose your API keys publicly. Ensure `.env` is included in `.gitignore`.

## Usage

Inquira provides flexible interaction modes: an interactive CLI terminal session, single command-line queries, batch processing, and provider/model switching.

### 1. Interactive Mode

Run without arguments to start an interactive Q&A session:

```bash
uv run main.py
```

### 2. Single Question

Ask a question directly from the command line:

```bash
uv run main.py "What is retrieval-augmented generation?"
```

Or specify `--json` for machine-readable JSON output:

```bash
uv run main.py --json "What is retrieval-augmented generation?"
```

### 3. Multi-Provider & Model Selection

Switch between OpenAI and Anthropic providers and select custom models:

```bash
# Query OpenAI with a specific model
uv run main.py -p openai -m gpt-4o "Explain quantum computing."

# Query Anthropic Claude
uv run main.py -p anthropic -m claude-3-5-sonnet-20241022 "What is LangChain?"
```

### 4. Batch Processing

Process multiple questions in parallel:

```bash
uv run main.py -b "What is Python?" "What is JavaScript?" "What is Rust?"
```

### 5. Run Demos

Run built-in test demos (`qa`, `batch`, `error`, or `all`):

```bash
uv run main.py --demo
uv run main.py --demo error
```

### 6. Monitor with LangSmith

When LangSmith tracing is enabled, you can inspect LLM interactions, execution traces, and debugging information through the LangSmith dashboard.

## How It Works

Inquira follows a straightforward question-answering pipeline:

1. **Input** — The user submits a natural language question.
2. **Processing** — LangChain orchestrates the interaction with the configured LLM.
3. **Generation** — The model generates an answer based on the input.
4. **Validation** — The response is formatted and validated against a predefined schema.
5. **Output** — The application returns the structured response.
6. **Observability** — LangSmith can trace LLM interactions for debugging and monitoring.

### Response Structure

An example of the structured output:

```json
{
  "answer": "Paris is the capital of France.",
  "confidence": 0.98,
  "sources": []
}
```

> **Note:** Confidence scores are generated by the language model and should not be interpreted as statistically calibrated probabilities of correctness.
